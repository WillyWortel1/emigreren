# Emigreren

Stappenplan, afvinklijst, fiscale laag en e-mails voor vertrek uit Nederland.

## Openen

1. Download deze map (Code → Download ZIP) of alleen `Emigreren.html`.
2. Dubbelklik `Emigreren.html` (één bestand, werkt alleen) **of** `index.html` (heeft de andere bestanden ernaast nodig).
3. Open in Safari, Chrome of Firefox — niet in Voorvertoning en niet in de chat.

Voortgang blijft in de browser op dit apparaat.
