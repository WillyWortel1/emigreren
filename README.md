# Emigreren

Stappenplan, afvinklijst, fiscale laag, e-mails en sociale updates voor vertrek uit Nederland.

Grok.me is een apart project (id `01a0f1ac-cbab-7ec1-9d4a-6b0bc882b8cc`). Het is geen automatische spiegel van GitHub. Na een wijziging in Grok: publieke bestanden `/emigreren/app.js`, `data.js`, `fiscal.js`, `styles.css` overnemen en naar `main` pushen. Cache-parameter in `index.html` ophogen (`?v=26` enz.).

Open lokaal `index.html` of `Emigreren.html`. Voortgang staat in localStorage op dit apparaat.

## Wat erin zit

- Zes fases: oriëntatie → voorbereiden → afronden in NL → vertrekweek → aankomst → eerste jaar
- Taken die meebewegen met bestemming en situatie (woning, voertuigen, huisdier, uitkering)
- Tabbladen: stappenplan, afvinklijst, fiscaal, e-maillijst, sociaal, spelregels
- Geen aangifte-module, geen automatische verzending, geen vervanging van een fiscalist
